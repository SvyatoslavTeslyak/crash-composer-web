# Crash Composer web

Runtime build for GitHub Pages. The source repository is private.

Sign in with an invited Composer account. Workspace roles, invitations and
translation drafts use Supabase. Goat Road optionally connects to Lotomobil QA
through an authenticated Supabase Edge Function; demo play requires no player login.

Brand, font, icon and audio file editing and game rebuilds currently require the
local Composer. The online edition labels these controls as unavailable.

Static web assets are public. Workspace data and mutations are protected by
Supabase authentication, membership and server-side permission checks.
